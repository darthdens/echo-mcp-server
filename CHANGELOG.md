# Changelog

## 1.0.0

- Initial public release of the Echo AI remote MCP server.
- Streamable HTTP transport (MCP spec 2025-06-18) at `https://auth.echoai.so/functions/v1/mcp`.
- OAuth 2.1 with PKCE and Dynamic Client Registration.
- Tools: `list_echos`, `get_echo`, `get_embed_snippet`, `get_headless_integration`, `get_echo_analytics_summary`, `list_recent_conversations`, `get_conversation_history`, `send_message_to_echo`.
